# LiewMk Barkadahan Cafe

A modern website for LiewMk Barkadahan Cafe — homemade silog meals, billiards, printing services, and more in a cozy hidden spot.

## Live Site

Visit [LiewMk Barkadahan Cafe](https://liewmk-barkadahan.github.io/Cafe/)

## Tech Stack

- Vue 3 + Vite
- Vue Router
- Iconify (MDI icons)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
